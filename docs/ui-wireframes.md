# UI界面线框图与操作说明

## 界面设计图说明

本文档通过文字描述展示每个界面的详细布局，便于视觉设计师创建实际的UI界面。

### 1. 首页界面

**整体布局**
- 顶部：应用名称"宝宝英语短句乐园"
- 中部：老虎角色动画区域（占据屏幕40%）
- 进度显示：横向进度条 + 百分比文字
- 功能按钮：圆形"开始学习"大按钮
- 底部：勋章展示和家长入口

**视觉元素细节**
- 老虎采用2D卡通风格，圆润可爱
- 进度条采用渐变色（绿到橙）
- 按钮有阴影和按压效果
- 勋章显示金色边框

**交互流程**
1. 打开APP，老虎眨眼欢迎
2. 显示今日学习任务
3. 点击"开始学习"，按钮有弹跳动画
4. 长按"家长"图标3秒进入家长模式

### 2. 学习流程界面

#### 2.1 情景动画界面

**布局**
- 全屏动画播放区域
- 底部中央：播放按钮（带阴影）
- 顶部左侧：返回按钮
- 动画结束后显示"再听一遍"

**动画设计**
- 每个句子配有10-15秒专属动画
- 动画场景简单，突出关键元素
- 语音泡泡显示正在播放的句子

#### 2.2 跟读练习界面

**布局**
- 顶部：老虎听音图标（会随录音变化）
- 中部：句子大字显示
- 底部：录音按钮（圆形，带录音波形）

**录音按钮设计**
- 默认状态：白色圆形，麦克风图标
- 按住状态：变红，显示录音波形
- 松开后：显示"说得真好！"文字

#### 2.3 游戏界面

**找图片游戏**
- 显示3个图片选项
- 语音播放句子
- 点击正确图片后，图片放大并显示"✓"
- 错误时图片摇晃但不显示答案

**选句子游戏**
- 显示1张图片
- 显示3个句子选项
- 每个选项是一个大按钮
- 正确选项有绿色边框，错误保持原样

### 3. 复习界面

**列表设计**
- 每个复习项显示：
  - 句子预览
  - 复习状态图标
  - 最后复习时间
- 滑动可删除不需要复习的句子

**状态图标说明**
- 🔵 蓝色圆圈：需要立即复习
- 🟡 黄色圆圈：按计划复习
- 🟢 绿色对勾：已掌握

### 4. 家长管理界面

**数据展示**
- 学习统计用简单图表展示
- 每日/每周数据用卡片形式
- 导出按钮带下载图标

**设置项**
- 时间限制：滑动条选择
- 护眼模式：开关按钮
- 声音设置：音量滑块

### 5. 贴纸收集界面

**贴纸布局**
- 网格布局展示贴纸
- 未获得的贴纸显示灰色轮廓
- 已获得的贴纸有光泽效果

**特殊效果**
- 收集新贴纸时有闪光动画
- 点击贴纸显示收集时间
- 可将贴纸设为壁纸

## 操作说明详解

### 1. 首页操作

**开始学习**
- 点击"开始学习"按钮
- 进入今日第一个句子学习
- 如有未完成的学习，先继续未完成的

**查看老虎状态**
- 老虎会根据时间显示不同状态：
  - 早晨：精神状态
  - 晚上：困倦状态
  - 完成任务：开心状态

**进入家长模式**
- 长按底部家长图标3秒
- 输入简单密码（4位数字）
- 进入家长管理界面

### 2. 学习流程操作

**情景动画**
- 自动播放，无需操作
- 播放完毕可点击"再听一遍"
- 点击后返回首页

**跟读练习**
- 按住录音按钮说话
- 说完后松开按钮
- 系统自动识别，只要有声音就通过
- 点击"下一步"进入游戏

**游戏巩固**
- 听句找图：点击对应的图片
- 看图选句：点击正确的句子
- 每个游戏有3道题
- 完成后自动进入下一环节

### 3. 复习操作

**自动复习**
- 系统自动提示需要复习的句子
- 点击开始复习进入学习流程
- 复习和全新学习流程相同

**手动选择**
- 可点击任意句子进行复习
- 按住句子可查看详细信息
- 向左滑动可暂时跳过复习

### 4. 家长操作

**查看报告**
- 显示学习统计数据
- 可选择查看周/月报告
- 数据以图表形式直观展示

**导出功能**
- 点击"生成PDF卡片"
- 系统生成包含：
  - 句子列表
  - 每个句子的配图
  - 音频二维码
- 保存到相册或直接打印

**设置控制**
- 时间限制：滑动选择每日最大学习时间
- 护眼模式：开启后定时锁屏
- 声音设置：调整音量大小

### 5. 贴纸操作

**查看贴纸**
- 点击"我的贴纸"进入贴纸册
- 按类别浏览已获得的贴纸
- 点击贴纸查看获得时间

**获得新贴纸**
- 完成每日任务获得
- 连续学习7天获得额外贴纸
- 生日时获得特殊贴纸

## 设计注意事项

### 1. 视觉设计
- 所有颜色柔和，避免刺眼
- 按钮足够大，便于幼儿点击
- 文字最少化，以图形为主

### 2. 交互设计
- 所有操作都有即时反馈
- 无复杂的滑动或手势
- 错误操作不会退出应用

### 3. 音频设计
- 语音清晰缓慢
- 背景音乐轻柔
- 操作音效积极正面

### 4. 性能考虑
- 动画流畅不卡顿
- 快速响应用户操作
- 内存占用最小化
